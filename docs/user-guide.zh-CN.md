# Chosuta 操作与估计规则

## 导入与选轨

打开 SVP、UST、VSQX 或 `.chosuta`。SVP 实际读取 mainGroup/mainRef 与轨道引用的 library 分组，未引用分组不产生演唱事件；同一分组多次引用保留实例。界面不猜测轨名是否主旋律：默认第 0 轨，用户勾选所需轨道后点击“生成口形”。优先级小值优先，平级按源轨顺序；默认主轨休止允许和声接管，可在规则页关闭。

选择与规则修改保存到工程；**修改后需点击生成，使新设置作用于口形**。生成在工作线程运行，可取消。静音轨道/引用/音符不生成事件；休止保持在轨道竞争之后求值，不遮挡可接管的和声。

输入保留整数 blick（四分音符 705,600,000），不量化到 480 PPQ；BPM 保留原精度并分段换算，拍号用于小节/拍定位。允许单个 NUL 尾部；JSON 直接由 Qt 解析，文件上限仍为 64 MiB。参考缺失会诊断，零/负时长音符跳过。最多 200,000 个实际引用音符 / 500,000 个生成分段；超长读音文本标为未知。

源 `startTimeSeconds` 保存在来源中，当前不擅自合并到动画或配音时间轴。动画同步和音频起点分别在导出设置中明确指定。原始用户文件不会被改写。

### UST / VSQX（0.10.0，首批实现）

可从“打开乐谱 / 工程”选择文件，也可拖入单个文件；CLI 的 inspect/generate/export 使用同一入口。先将下载包中的 `.ust` 或 `.vsqx` 解压到自己的文件夹，再打开工程文件；应用不直接导入ZIP，不自动加载其中的音频或声库。

- UST：一次打开一个文件/声部，支持UTF-8与CP932，按Length累计位置、逐音Tempo变速；R为休止，保留首尾休止时长。识别日文CV与常见VCV前缀；原始别名仍显示和保存。声库自定义后缀、特殊别名若读不出，可在读音编辑处修正，不加载oto或resampler。
- VSQX：接入VSQ3/VSQ4字段结构，读取轨道、part、音符、显式音素、歌手语言、静音/独奏、速度及拍号。按实际resolution换算，移除preMeasure对应的前置小节，并保留原始位置/分辨率；part长度外的音符不作为该part的有效演唱。独立公开材料为VSQ4，VSQ3尚无原软件对照。
- VOCALOID显式音素目前提供日语/英语常用X-SAMPA映射，继续使用估计时序及现有辅音设置；音素内的`-`可延续同part前音的元音。未知符号、未提供映射的其他语言保留为未知，可人工修正。空音素才按歌词处理，不用歌词掩盖无法解释的显式音素。
- 不复原调声曲线、声库别名全部语义或合成后的音素边界；歌声仍是乐谱驱动。多个UST的合轨、LAB/DS、VVPROJ和其他格式属于后续阶段。

保存继续使用schema14，新增sourceFormat记录来源类型，嵌入原始文件字节；关闭后重开按该类型恢复，不依赖原文件后缀或原文件仍存在。已有schema14的SVP工程没有sourceFormat时仍按SVP读取，schema13及更旧工程的规则不变。较旧Chosuta不支持新加入的UST/VSQX来源。

已完成Linux构建及现有回归，5份UST与1份VSQ4完成CLI生成、保存和重开元数据对照；尚未完成Windows及原合成软件兼容验收。

## 读音与特殊项

顺序为：逐音符人工读音修正 → 非空显式 phonemes → 用户词典 → 内置歌词规则/词表 → unknown；锁定事件覆盖仍优先于重新生成结果。空显式音素走歌词规则，空歌词走独立可配置策略，不认为已证明无声。属性中的逐音素修正与顶层 phonemes 分开；leftOffset 原值保存并显示来源路径，单位/基准未核实所以不应用。

- 日语：支持全角/半角假名规范化、平假名/片假名五元音、浊音/半浊音、拗音、小假名、促音、鼻音、长音与常见罗马音。默认不估计日语汉字，也不套用中文读音；可输入假名/明确音素。高级设置的汉字估计开关默认关闭，启用后使用原创 192 条常见读音，不能保证多读音、词义或跨音符分配准确。样本中的假名全有规则。罗马音未识别时给出 unknown。
- 中文：原创 50 条常见词语读音优先，其他汉字使用 ICU Han-Latin 默认读音，或拼音/带声调拼音。保留 ü（也接受 v / u:）后去除声调；数字声调可分隔音节，如 ni3hao3。非空显式音素按音素解析，不当作拼音猜测。默认读音不保证多音字或句中语义正确，可逐来源音符纠正。
- 英文：原创 562 个常用词；可加载本地 CMU 格式 `word PHONEMES` 词典（与内置及自定义数据合计不超过 3 MB，优先首发音，忽略注释和编号变体）。内置词表并非完整词典，词典外词保持 unknown。明确音素可用 ARPAbet；双元音展开为两个差分，如 AY→A/I、OW→O/U。

来源工程给出语言时按逐音符覆盖 → 分组 → 轨道继承处理，未知语言保留诊断，不误用英文规则；用户可在规则页明确选择 ja/zh/en，不由界面语言决定。工程未给语言时可检测假名/汉字，其他未确定情况默认日语；英文歌曲应明确选择英文。兼容全角拉丁文字；自动模式也能识别词表中已有英文词。日文罗马音中的 n' 保留鼻音分界。未知读音显示橙色与诊断来源，可选事件点击“修正读音”，或直接替换差分。读音留空撤销该来源的修正。

时序仅是动画估计：每个音节平分对应乐谱区间；前导辅音默认占音节 18%（规则页可调 0–80%），按下表区分需要闭口和不闭口的辅音；其余元音/词尾确定性分配剩余时间。单独元音占完整音符；双元音平均分配；不模拟声学模型或 SV 私有边界。

0.6.0 新导入工程使用推荐的二元动画规则，通常无需修改：

| 来源 | 推荐默认闭口 | 跟随相邻元音（例） |
| --- | --- | --- |
| 英文 ARPAbet | B/P/M | D/T/K/G/CH/JH/L/N/NG/S/F/V/W 等 |
| 日语假名 / 罗马音 | ば/ぱ/ま行及对应拗音；b/p/m/by/py/my | か/が/た/だ/さ/な/は/ら行等；k/g/t/d/ch/ts/j/r/n 等 |
| 中文拼音 | b/p/m | d/t/g/k/j/q/zh/ch/z/c/l/n/s 等 |

跟随元音指前导优先后方、尾部优先前方的同音节元音；无元音时用 I 作为估计回退。不建模半闭细节，f/v/w 的细部唇形也只作二元近似。cl、独立鼻音、呼吸与休止继续走各自特殊策略，英文 N/NG 不误当日语独立鼻音。

高级差分设置的“辅音规则”页默认收起调整入口；展开后按来源语言/音素体系查看默认/当前分类，逐项选择跟随元音或闭口，可恢复此项/全部默认。规则更改显示“应用并重新生成”，可撤销，锁定人工覆盖保留，旧波形校正清除；只换素材或高级外观开关不重新生成。设置保存到当前工程，不自动改变其他工程默认。

新导入工程采用有上限的辅音组预算：短音节按比例，长音节的前导/尾部辅音组分别最多 80 毫秒，组内多个辅音共享预算，两组合计最多占音节 80%，保留元音时间。纯辅音和特殊项不会被硬截成 80 毫秒。“规则”页可调整“辅音占音节比例”和“辅音组时长上限”，参数保存到工程，点击“生成口形”才应用，锁定人工覆盖仍保留。上限 **0** 表示不设固定毫秒上限，仍受音节比例预算约束。默认值是动画估计参数，不是声学准确边界；逐音素开闭分类可在高级差分设置调整；逐音素半闭程度/声学时长模型未实现。

`+` 使用同一分组引用实例内前词的后续音节；多个 `+` 逐个分配，最后一个承接剩余音节，音节不足则标未知。`-` / `ー` 保持最近元音，避免保持词尾闭口辅音；不会跨分组沿用状态。兼容全角 `＋` / `－`。cl、br、空歌词、鼻音、休止、延音分别可配置：立即指定差分、持续保持、保持指定秒数后指定差分。休止默认 rest，空歌词默认 unknown，cl/鼻音默认 closed，br 默认 breath，延音默认保持。

## 高级设置与自定义词典

打开 **设置 → 高级设置 → 读音词典**，可以添加、编辑、删除三语词条，也可导入/导出 Chosuta JSON 词典。双击单元格编辑；语言和格式使用下拉选项。英文通常选择“音素”，如 `hello` → `HH EH L OW`；中文选择“假名 / 拼音 / 单词”，如 `行` → `hang2`；日文可填写 `銀河` → `ぎんが`。英文音素中的 `|` 可以指定音节边界，如 `G OW L | D AX N`；字典是读音映射，不代表 SV 的声学边界。

自定义词条优先于内置读音；不得覆盖逐音符人工修正、来源显式音素或锁定事件。日文自定义读音是用户明确指定，即使汉字自动估计关闭也能使用。未知读音可以继续按原有逐音符方式修正。

点击“保存”后设置进入当前工程，**重新生成口形**才能应用；随后保存 `.chosuta`，以携带词典/汉字开关供另一台机器或下一次重开使用。默认勾选“同时保存为新导入乐谱的默认设置”，使设置也存入应用的用户配置，重启后导入新乐谱 自动采用；取消勾选只影响当前工程。打开已保存 `.chosuta` 时始终使用该工程自己的快照。

内置三表共 **13,796 字节**；内置源表、自定义紧凑 JSON 和可选外部 CMU 文件的合计上限是 **3,000,000 字节（3 MB）**，不是 RAM 限额。重复词、无效格式、无法解析的读音或超限都会阻止保存/生成，保留现有配置。单词最长 128 个字符、读音最长 4,096 个字符；格式/预算按实际数据检查，不联网下载。词条编辑器按需创建编辑控件，避免每条都驻留多个下拉框。

“日文”标签内的 **估计日文汉字读音（可选）** 默认关闭，基本日文流程仍以假名为准。开启后有限词表的结果明确标为估计；不认识的汉字词仍显示 unknown。开关不更改原始歌词或显式音素，不要求外部大型词典，也不保证与 SV2 发音完全一致。

导出 JSON 同时保存自定义词条和开关，格式如下（省略条目表示空词典）：

```json
{"version":1,"japaneseKanji":false,"entries":[{"language":"en","word":"hello","reading":"HH EH L OW","notation":"phonemes"}]}
```

词典导入是在高级设置里替换待保存的词条；点击取消不会修改当前工程或应用默认值。导出的词典没有内置表或歌曲内容，用户仍需自行判断自己词条是否允许分享。

CLI 支持同一格式与可选开关：

```sh
./build/chosuta-cli generate input.svp output.chosuta --custom-dictionary dictionary.json
./build/chosuta-cli generate input.svp output.chosuta --japanese-kanji
```

`--no-japanese-kanji` 可以明确关闭已存开关；与 `--japanese-kanji` 同时使用会拒绝。将文件放在任何下载目录不会自动安装或改变应用。

工程只读写 schema 14；不提供旧工程迁移或旧格式兼容。新工程仍完整支持保存重开。

## 差分组与独立演出（0.8.0）

默认使用简单模式，只需基础口形图。勾选“启用高级差分”后，显示演出属性页、顶部“生成演出”和时间轴演出行。关闭高级模式会保留素材、规则与人工编排。高级演出替换了旧逐音方向/幅度/节拍组合，不提供旧模式或旧工程迁移。

打开“设置 → 高级差分设置”：

- **差分素材**：左侧添加、复制、重命名差分组；右侧配置 A/I/U/E/O 和 closed/rest/breath 八个槽。每张 PNG 是完整立绘；同组宜保持身体位置和画布一致。逐槽选图可使用任意文件名；复制组共享图片路径。删除组须选择替代组，基础组不能删除。
- **自动档位映射**：把“收敛/常态/强调”分别指向自己的差分组。默认都指向基础组，因此不配新素材也能使用；映射相同不会产生身体变化。组名和配图不用于推断情绪。
- **规则标记**：A1–A3 是强调依据，R1 是收敛依据；没有“B固定代表收敛”的约定。素材槽 A 是 /a/ 口形，用户命名为 A/B 的差分组也没有固定力度，强弱由“收敛／常态／强调”的组映射决定。
- **自动演出**：根据到达音群、重复高区动机及段落音区背景提出建议；多个短音可共同支持强调，同音、短回绕和相容的短换气保持。持续回落、两个放宽的起音间距及结束边界共同支持时才收敛。主音、长音、句尾或小调本身不会触发收敛。
- 先选择“时长依据”（音乐时值／谱面经过秒数）和“音高距离依据”（半音／按音名的度数），再填参数；四分音符=1，不冒称6/8中的一拍。两套参数分别记忆，只启用当前选择，切换不自动按BPM换算。度数无法确定时跳过并说明，不偷偷使用半音。常用参数显示在前，详细参数和条件表折叠；自定义规则也跟随选择，较高优先级先匹配，同级按行序，仍服从自动最低保持。
- **辅音规则**：仍决定嘴形与发音时序。修改后明确重新生成口形；演出规则、差分组和人工演出操作不清时间校正。
- **批量导入**：选择多个 PNG、拖入一批 PNG，或扫描一个文件夹。每行可指定目标差分组和口形，也可多选行后统一指定组；可以新建组。文件名符合 `A/I/U/E/O/closed/rest/breath.png` 时自动建议口形，任意其他名称可手工指定，不必重命名原图。父目录按直接子目录建议分组；单组目录填当前组，不扫描更深层或符号链接。新增默认勾选，替换需勾选确认；坏图不可导入，多个勾选文件指向同一组同一槽时阻止整批提交。先导入设置草稿，再点击底部“应用”；取消不改工程或原图。点击文件行查看缩略图。旧组合名也可手工映射，不恢复旧方向规则。

选图顺序为“当前差分组的当前口形 → 基础组同口形 → 全局回退图”，闭口/休息/呼吸同样适用；不用集齐八张。缺少某组闭口图时，可能回到基础闭口的身体动作；需要保持一致时补该组闭口图。所有候选均不可用才报缺图。图片按需、同路径共用、有界缓存，既有 256 MiB 单图限制、512 MiB 缓存目标不等于总内存限制。

### 应用设置、比较和人工编排

高级设置底部的“应用”会在需要时后台更新自动演出，并一次提交设置与结果；无需再点“生成演出”。期间可取消，失败或取消不提交工程，受保护人工段保留，整次操作可撤销；仅换图片且自动结果仍有效时直接更新素材。修改辅音规则仍会重生成口形并清除旧波形校正。

如需先比较再决定，可单独点击“生成演出”生成草稿，可取消。完成后可在同一预览里切换“当前/草稿”，定位或播放比较；点击“应用”才一次提交，“取消”保留当前结果。口形、人工口形覆盖和波形校正分别保存，不会随演出重算消失。在高级设置之外修改来源、区域调性或人工分句边界后，自动结果会提示待更新，可使用生成草稿；启动和保存本身不触发重算。

时间轴顺序为标尺、可选波形、口形、演出、可选字幕。演出行默认 56 像素，可拖高至 40–120，也可隐藏；这些是本机偏好。虚线表示估计的分段建议，不等于已确认乐句。

例如想把某一段固定为自己画的“激昂”差分组：

1. 在时间轴的**演出行**点击自动区块，或按住鼠标拖出范围；左侧切到“演出”页。起止时间也可直接输入。
2. 模板选**保持**，目标选**激昂**这个差分组（或已映射到它的“强调”档位）。
3. 保持“保护人工段”勾选，点**应用人工演出段**。该范围身体使用此组，嘴形仍随演唱变化。
4. 需要改回去时选择人工段，点**删除人工段**显示原自动结果，或用 Ctrl+Z 撤销。模板“收敛”是用户指定的切换顺序，不要求满足自动收敛规则。

选中自动段时属性栏会填入它当前的差分组，不沿用上一人工模板。“保持”仅显示一个目标；其他模板按时间顺序显示三个目标与切换百分比。判断依据可展开查看。

在演出行单击选择区段，拖空白或自动段框选范围；这些操作不会移动播放位置，定位仍使用标尺。在左侧先选择“时间显示”：视频秒或“小节:拍:拍内比例”（例如 `2:1:0`），再设置起止。显示切换不移动区段；“跟随乐谱／固定视频秒”是独立的时间锚定选择。设置模板和目标后应用：

| 模板 | 默认目标 | 初始切点 |
| --- | --- | --- |
| 保持 | 一个档位或指定差分组 | 无 |
| 展开 | 收敛→常态→强调 | 33%、67% |
| 收敛 | 强调→常态→收敛 | 33%、67% |
| 先展开后收敛 | 常态→强调→常态 | 35%、70% |

目标和百分比可改。谱面锚定的百分比按音乐位置换算，固定秒按秒换算；都是整图直接切换，不生成中间动作。可拖人工段中部移动，拖边缘改变范围，靠近口形边界时吸附（Alt 暂停吸附）；框线预览落点。覆盖其他人工段只替换重叠部分，保留外侧。拆分保留原模板进程，不重新从模板开头播放；合并后一个紧邻人工段会保留可见切点，保存为固定视频秒的合并模板。

人工段默认受保护。“重生成选区”保留受保护段，清理该范围内未保护的覆盖；取消保护本身不改变画面。“选区恢复自动”也先显示草稿，应用后才移除选区人工覆盖。Delete 只删除选中人工段并显露下层自动计划，不能删除纯自动段；要压住某段自动动作，可应用“保持→基础组”。操作可撤销。

“口形”属性修改仍随差分组变化；勾选“固定整图”才将该事件固定为指定图片。演出段保持身体不会冻结嘴形。来源消失的人工演出保留保存时的时间并诊断；可重新调整锚定，系统不凭名称猜来源。有效波形校正只影响谱面锚定区段的时间映射，同步偏移只应用一次；固定视频秒保持不动。

### 可选调性与分段修正

自动演出页选择是否启用调性辅助，再分别选择主音与调式。例如主音选“B♭（降）”、调式选“自然小调（Aeolian）”；无需输入升降号或英文简写。C♯与D♭保留不同拼写，支持七种教会调式、和声大小调、上行旋律小调与自定义七音；旁边显示音阶。逐音音名仍可编辑且必须匹配原MIDI音高。无已声明调性或明确音名时，度数证据不可用。

“设置选区调性”提供继承全局／指定／禁用，指定使用同款主音、调式选择器；重叠旧区域只裁切交叠部分。调性用于音名、音程、动机比较及音级解释，不推断真实强弱、和弦、唱法或情绪。CLI仍接受 `C maj` / `D Dorian` 等文本。

“乐句分开／连接”调整局部候选，“段落分开”重置背景；“段落连接”允许明确衔接，“自动边界”移除该处人工标记。操作针对范围起点之后实际路由的来源音符，下一次生成草稿才应用。短呼吸可以保留相容背景；跨轨衔接需明确的段落连接。自动边界与有限重复动机只是谱面候选，不保证真实分句。

草稿比较显示改动时段，选择区段可查看原因与来源ID。通常/强调映射同组时显示提示；缺槽仍按基础同口形和全局图回退。自动规划不使用波形，也不自动对齐外部歌词或识别歌词情绪。对无法从谱面确定的轻唱/强唱，请用受保护人工区段表达。

保存新工程默认是显式勾选项，只保存通用参数及“全轨道、以档位为目标”的规则；特定组/轨道规则仍保存于当前工程。工程自身的设置不被默认值覆盖。

CLI 示例：

```sh
./build/chosuta-cli generate song.svp song.chosuta --advanced-mouth --key "D Dorian" --generate-performance
./build/chosuta-cli generate song.chosuta with-images.chosuta --variant-assets images
./build/chosuta-cli generate song.chosuta edited.chosuta --performance-json performance.json --generate-performance
./build/chosuta-cli export with-images.chosuta movie.mov
```

`--assets` 扫描基础口形图；`--variant-assets` 扫描差分组目录。`--performance-json` 使用当前工程 `performance` 对象的完整 JSON（规则、组、档位、区段、边界与调性）；严格校验，不执行代码。`--performance-info` 在 generate/export 等有输出路径的命令中输出该对象，供检查。CLI 的 `--generate-performance` 表示直接接受生成结果，仍保护人工段；GUI 提供交互草稿比较。

## PNG 与预览

导入多张 PNG 时按不含扩展名的文件名映射（a/i/u/e/o 自动大写）；双击映射可以选择任意文件名。支持自定义差分 ID，缺少某差分时使用所选回退。个别无效/缺失映射显示诊断并使用回退。默认图像等比居中缩放，画布页可调整大小与中心位置；透明由 PNG alpha 合成。单图读取上限 256 MiB，场景解码缓存上限 512 MiB。

没有立绘时“创建测试素材”在用户选取目录绘制原创几何图形；它不覆盖该目录已有同名文件。预览与导出使用同一事件解析和合成器，预览保持导出画布比例。

## 画布与背景

顶部“画布 / 背景”入口和左侧同名页提供 16:9、9:16、4:3、1:1 预设及自定义分辨率，背景颜色、透明画布、自定义背景图片和立绘布局。分辨率、比例、背景不再放在导出设置里。背景图片支持当前 Qt 图像插件可读的 PNG/JPEG/WebP/BMP；填满模式保持比例并居中裁切，完整显示模式留出背景色边缘，拉伸模式铺满画布。透明画布不会自动去除背景图片或立绘的实色。

立绘大小 100% 表示等比适配画布，中心 X/Y 的 50%/50% 为居中；可缩小、放大和移出画布，超出的部分裁切。停止播放后，在预览上方选择“拖动立绘布局”，拖动立绘框移动，拖动右下角手柄等比缩放；Esc 取消，松开后一次提交撤销。数值控件仍可精调和重置。预览和视频共用合成器，设置支持撤销、保存和素材重定位。背景丢失或无法读取时有诊断，导出明确拒绝；不悄悄导出缺背景的视频。

动画时长 0 表示随乐谱及有效人工事件；可手动设置正数、向后延长至完整音乐的长度，不依赖音频。允许最长 6 小时。时间轴支持在乐谱尾部之外定位，尾部保留空白余量；定位本身不更改已设视频时长，延长视频需修改画布中的时长。

## 设置与播放

“设置 → 偏好设置”配置界面语言。界面语言默认“跟随系统”：按系统语言列表选择中文/日文/英文，均不支持时用英文；手动选择会持久保存，切回“跟随系统”后恢复自动选择。运行时收到 Qt 系统区域变化通知时也会更新界面，系统未通知时需重启。歌词语言仍由来源工程或规则页决定。

空格统一控制播放/停止，包括按钮、差分下拉框和时间轴获得焦点时；按住空格的自动重复不会反复切换。在可编辑文字框内仍正常输入空格；模态对话框使用自己的键盘操作。播放游标接近可见时间轴边缘时自动滚动，秒/拍显示均适用。极长动画超过控件宽度限制时自动降低有效缩放，保证尾部仍可访问。

**运行控制**只提供统一的“播放／停止”操作和“停止时回到本次播放起点”开关，不再单列重复的停止按钮或暂停操作。空格、画布下方“播放／停止”按钮、菜单里的同名项完全一致：启用返回开关，停止回到本次按下播放时的起点；关闭开关，停止留在当前位置。播放中定位不改变起点，每次重新播放会记录新的起点。蓝色虚线显示本次起点，开关保存为应用偏好；默认关闭。自动到末尾仍停在末尾，旧工程固定返回点不参与新控制。

时间轴新增**游标：不吸附／吸附节拍／吸附音节**。节拍按当前位置拍号的分母单位与变速表定位（如6/8吸附八分音符格）；音节按所选轨道的谱面歌词边界、连续延音范围及有效时间映射定位，不识别音频中的真实发音。点击或拖动标尺时取最近边界，Alt 临时关闭；输入精确秒数及正常播放不吸附。显示秒／拍与吸附开关彼此独立，选择保存为应用偏好。

主窗口可拖入单个 SVP／UST／VSQX／Chosuta 工程打开、单个常见音频文件附加（WAV/FLAC/MP3/OGG/M4A/AAC，实际解码能力取决于本机后端），或 PNG／单个文件夹进入批量映射审阅。高级素材页可直接把一个 PNG 拖到指定口形槽；这只修改当前设置草稿。仅接受本地文件，不下载网址。

## 时间轴与人工覆盖

拖动事件中部移动，拖动边缘缩放；Ctrl 点击多选，Ctrl 滚轮缩放。点击空白或输入播放位置定位。秒/毫秒与小节/拍显示切换不修改事件。可用属性编辑起止、口形、锁定和锚定；多选“应用”替换口形与锚定，时间移动使用批量偏移。负事件起点允许保留，导出从视频 0 秒开始。

秒锚定固定绝对秒数；拍锚定保留整数音乐位置，未来速度改变时跟随。拆分使用当前播放位置；合并覆盖所选区间、使用最早事件口形并保留父来源。人工片段有独立编辑 ID。发生重叠时人工覆盖优先，再按较晚起点和稳定 ID 决定。删除、移动、替换、拆分、合并、批量偏移、规则与素材变更支持撤销/重做。

重生成保留锁定修改，未锁定修改会被替换。来源事件消失时覆盖保留为孤立记录并在诊断页列出，暂不播放；拆分/合并的父事件消失也遵守此规则。重新选回原来源并生成可恢复匹配；“重置全部人工修改”可撤销。

保存工程 schema 14（只读写当前格式），嵌入原始来源及sourceFormat、来源校验哈希、生成事件、覆盖及其来源片段、读音、素材、选轨/优先级、画布布局、字幕启用状态/各轴/文字/样式/时间锚定、独立波形时间校正与上限、差分组/档位/演出自动与人工层/规则/区域调性、动画时长与导出设置，采用临时写入后原子提交。文件整体上限 64 MiB；大源文件加上嵌入/事件层超限时会明确拒绝保存。原始来源文件可移动而不影响重开；图片（含背景）/音频/外部词典用相对路径，移动后“重定位素材”按原文件名匹配目录。波形摘要只在当前会话缓存，不嵌入工程。

## 可选字幕与鼠标布局

默认不显示字幕轴。勾选时间轴工具栏的“添加字幕”，首次建立一条空轴，并显示左侧“字幕”页。取消勾选隐藏字幕轴且停用字幕预览/导出，数据保留；再次勾选或重开启用的工程可恢复。字幕用于口形视频的文字叠加，不提供视频剪辑、识别、关键帧或逐字特效。

- 轴内鼠标播放定位集中在上方独立的秒/拍标尺带，点击或在带内拖动定位。红线保持贯穿全轴。单击口形/字幕轴空白或块间留白只取消选择、退出文字编辑并保留输入，不改变播放位置；选中、编辑或新建字幕也不会自动跳到字幕中点。
- 在目标字幕轴空白处双击，于鼠标时间创建默认 2 秒字幕（末尾受六小时上限约束）。单击已有字幕用于选择/删除，中部拖动移动、左右边缘调时长；双击才在块内编辑文字，可见插入光标和选区。文字即时保存，样式与时间字段修改后点击“应用字幕与样式”。短块编辑框可略宽于块，仍按原时间保存；只使用一个当前编辑控件，侧栏通过“在字幕块中编辑文字”进入同一编辑。
- 非文字编辑时，时间轴/预览的 Delete 或 Backspace 删除所选字幕/口形；文字编辑时只删除字符、空格只输入空格。点击空白结束编辑后，空格恢复播放/停止。Enter 换行，Ctrl+Enter 或 Esc 结束编辑并保留文字；F2 可编辑选中字幕。Ctrl+Z/重做使用工程撤销，保存点后的输入可独立撤销。播放/后台任务期间不执行对象删除或进入文字编辑。
- 拖动口形轴/字幕轴下边界调整行高，拖动主区域与时间轴之间的分隔条调整显示区域；“恢复轴高度”恢复紧凑默认值（发音/口形行 96、字幕行 60、波形行 80 个逻辑像素）。发音行上下留白已收紧；既有手动高度继续保留，想采用新的紧凑高度可点击恢复。口形/标尺保持可见，高度受可读最小值和窗口空间约束。高度是视图设置，不改变视频字号、时间区间或导出；应用保存默认行高/区域高度，当前各字幕轴可分别调整。
- “新增字幕轴”可添加译文、第二行或说明，每轴有名称、启用状态与默认样式，最多 64 轴。不同轴可同时显示，按轴顺序叠放；同轴新建/改时间产生重叠会拒绝，保留原数据，可改时间或在其他轴添加。导入文件中已有的重叠保留并诊断，不静默删除。
- “对齐歌词”默认关闭，开启后明确选择“歌词来源轨道”。命中歌词时采用该音符与同实例连续续音/延音范围；空隙中只吸附近处边界，没有附近歌词则保留手动区间。拖动边缘会吸附歌词边界，整体移动保持时间长度。多轨不自动混合或随口形优先级换来源。
- 一句字幕可在“起始歌词/结束歌词”选择范围后点击“使用歌词范围”；该明确选择允许跨同一来源轨道的引用实例。字幕文字由用户输入，不自动断句或将输入句子匹配歌词，也不输出 `+`、`-`、`ー`、`cl`、`br` 等控制标记作为默认歌词。
- 对齐依据谱面音符时间，允许微调，不是音频边界识别。关闭对齐不批量修改已有字幕；已有音乐锚定仍随乐谱及动画同步偏移，自由拖动该条目可转为固定视频秒数。音频偏移不再次作用于字幕。切换秒/拍显示、修正或重生成口形均不改字幕。
- 字幕页可选择系统字体、字号（画布高度百分比）、颜色/透明度、粗体、斜体、描边、文字框宽度与对齐、中心位置。“仅此字幕覆盖样式”关闭时应用轴默认样式，开启时只改当前字幕；清除此项并应用即可恢复继承。
- 停止播放后在预览上方选“拖动字幕布局：轴名”，拖动框移动，右下角调字号、右侧中间手柄调换行宽度。独立样式的字幕需先在时间轴选中再拖动；没有当前可见文字时没有可拖动框。数值调整、鼠标调整、删除、启用状态及时间编辑均可撤销和保存。拖动中 Esc 或开始播放会取消尚未提交的操作，播放/后台任务期间不开始鼠标编辑。

源歌词消失时保留字幕文字和上次保存/编辑的有效区间并诊断，不按同名轨道猜新来源。自动动画时长包含已启用字幕末尾；固定动画时长不自动改变，可点击“延长至字幕末尾”。字幕超出固定时长时显示诊断，GUI 导出前提供延长/按指定时长导出/取消选择。CLI 尊重指定时长，并输出诊断。

预览、CLI 和视频导出通过同一 Scene 绘字，选择框/手柄不进入视频。字体只保存字体族，不捆绑字体文件；缺失字体显示替代诊断，不同系统可能有排版差异。字幕条目总数上限 100,000，单条文字 4,096 个 UTF-16 单元，工程总上限仍为 64 MiB，字幕不占词典 3 MB 数据预算。

## 可选波形与时间校正

附加音频后，波形行出现在时间标尺下、音节/口形行上。后台通过已有 FFmpeg 分块解码，准备时有进度/取消；准备失败仅提示波形不可用，不影响工程生成或人工编辑，可点击“重读波形”重试。无音频时不显示波形行，不初始化声卡。波形与音节共用秒/拍转换、横向缩放/滚动和贯穿游标；拖动波形行下边界只调整高度/显示大小，应用记住默认高度，“恢复轴高度”可恢复。行高不改变工程、音频速度/时长或视频内容。波形空白点击不定位，播放定位继续使用时间标尺。点击波形或切换选择时，时间轴会保留波形行、发音行及首个字幕行所需空间，字幕轴不会因取消选择而被挤出显示区域。

**导入音频、显示波形不会自动校正。** 用户点击“按波形校正时间”后才运行无模型的能量边界估计。最大偏移默认 **100 ms**、可选 0–1000 ms；最大时长变化默认 **25%**、可选 0–50%。数值在点击校正时应用并随本次校正保存，不是精度保证，也不等同规则页的 80 ms 辅音群预算。偏移 0 不作调整；时长变化 0 允许保持长度的整体平移。

每个已生成的可见音符来源的口形段作为一个区间，在原工程时间附近独立寻找明确起音/结束变化；段内差分、身份与比例保留，不识别元音/辅音或选择图片。两端受最大偏移限制，总时长变化不超过指定比例；歧义、连续发声、未知/特殊项、已有人工覆盖、重叠或新冲突保留工程结果，显示本次调整/保护/不明确/冲突数量。候选先独立估计再联合校验；合理抢拍可越过旧相邻音符边界，校正后的顺序与间隔仍需合法。冲突回退相关候选并复查邻居，不推移后续。重复执行从工程基准重新计算，不累积移动。声部选择保持工程生成结果，不补出原来被优先级遮蔽的事件。没有内部边界识别；一个音符内多个音节只能整体校正，仍可人工改时。

“回退波形校正”清除独立校正层，恢复工程时间；原有人工覆盖和锁定修改保留。校正与回退都可撤销/重做，时间操作复用图片缓存。预览、保存重开及 CLI/视频导出使用同一有效事件结果；重新生成工程口形会清除旧校正并保留锁定人工修改。音频路径/大小/修改时间、工程生成内容、选轨/优先级、规则、速度或整体同步关系变化会使旧校正失效，回到工程时间并诊断；重读波形不自动重新校正。工程保存音频文件元数据和工程基准，不再保存或检查音频内容哈希。预览仅刷新时间层并复用图片缓存，不重复读取音频。

有伴奏的混音可以显示、试听和人工参考，自动能量建议不能可靠区分人声与鼓点/乐器，不保证歌声音节边界。优先使用同次渲染、具有正确时间原点的单轨人声；当前使用所附音频，不新增分析干轨/配音混音双文件管理或声部分离。高级差分可根据工程音高/音名选择方向和幅度；波形只提供时间依据。

CLI 显式操作（不覆盖已有输出时无需 `--force`）：

```sh
./build/chosuta-cli correct input.chosuta corrected.chosuta --audio vocal.wav --max-shift 100 --max-duration-change 25
./build/chosuta-cli revert corrected.chosuta original-timing.chosuta
./build/chosuta-cli export corrected.chosuta output.mp4
```

`correct` 也可接受 SVP，保留原工程生成快照、输出校正统计与波形摘要数据量；`inspect` 给出校正状态。控制参数分别为毫秒和百分比。Ctrl+C 取消，取消/失败不写半成品；新音频或规则参数使旧校正失效。无音频可继续常规 generate/export。

## 音频与导出

音频可选，不决定口形内容；可供主动触发的可回退时间校正。附加本地音频时由独立 ffprobe 后台读取时长，不分析发音；若含偏移的音频结束时间超过当前动画，会询问是否延长，拒绝则保留原时长。画布页也可“使用音频时长”。缺少 ffprobe 或时长未知时提示手动设置，不阻止附加音频；损坏或没有音轨的文件明确报错。附加本地音频后可试听；预览由单调时钟驱动，定位与音频偏移同步。正音频偏移添加前置静音，负偏移裁去音频开头；短音频补静音至视频结束。真实声卡播放仍需桌面环境验收。

导出设置支持有理帧率 NUM/DEN、格式、CRF 或目标 kbps、动画/音频偏移和 FFmpeg 路径；尺寸、背景、透明和时长在画布页设置。MP4/WebM 的 4:2:0 尺寸需偶数。码率体积仅估计视频部分，不含音频/封装；CRF 不承诺固定体积。

| 格式 | 视频 / 音频 | 像素格式 | 透明 |
| --- | --- | --- | --- |
| MP4 | libx264 / AAC | yuv420p | 不支持 |
| WebM | libvpx-vp9 / libopus | yuv420p | 当前不提供 |
| MOV | qtrle / AAC | argb | 支持 |

程序先检查编码器。事件是半开区间 `[start,end)`；帧 n 采样绝对 `n × fpsDen / fpsNum`，边界选后一事件。输出帧数为 `ceil(duration × fpsNum / fpsDen)`，完整末帧允许使封装时长向上不足一帧；音频编码/容器也可能产生轻微时间戳差异。内部事件不量化到帧。

FFmpeg 使用参数数组，不经过 shell。自动查找依次使用本机默认路径、程序目录下 `tools/ffmpeg/`、程序同目录、系统 PATH（Windows 自动处理 .exe）；工程路径优先于本机默认；指定错误不会静默切换。帧直接按有界管道送入编码器，不缓存完整 PNG 序列；同输出目录创建本次独有临时目录，成功后原子写入目标。编码完成后直接将同目录暂存视频移动到目标，不再复制一份成片。失败/取消只清理本次临时产物；已有文件需显式覆盖选择，取消保留旧文件。界面工作线程显示进度与取消，关闭运行任务时先请求取消，任务结束后可再次关闭；取消未保存确认则留在当前工程。有草稿时统一在一次保存询问中说明未应用草稿会丢弃。

## 扩展边界

当前已接入SVP、UST及VSQX，新增格式的范围与实际验证状态见本文开头。TimingRefiner 接收选区/来源/音频引用/原点，返回带事件/来源 ID、提供者/版本、输入哈希、置信度的独立提案；无提供者正常工作，提案应用跳过人工覆盖与过期输入。0.5.0 的无模型波形校正使用独立的来源区间时间层；不加载 SV 声库、识别/分离模型或缓存。0.7.0 使用独立演出区段与差分组替代旧逐音组合；PSD、其他工程格式及多角色高级编排留待后续；Live2D 不在范围内。


## 高级差分 CLI 示例

```sh
./build/chosuta-cli generate input.svp advanced.chosuta --advanced-mouth --assets poses
./build/chosuta-cli generate advanced.chosuta planned.chosuta --key "C maj" --generate-performance
./build/chosuta-cli generate advanced.chosuta simple.chosuta --simple-mouth
./build/chosuta-cli export advanced.chosuta advanced.mov --format mov
```

旧方向/幅度/拍位开关已移除；高级/简单开关保留已有生成快照和校正，--consonant-settings path.json 修改辅音规则并明确重新生成。--assets 使用与 GUI 相同的规范名扫描，未知名跳过并报告，坏图跳过并报告，重复目标采用最后一项；--force 才替换已有映射或已有输出。自定义辅音 JSON 为 `{"overrides":{"ja:romaji:d":"closed"}}`，分类仅 open/closed，键使用已支持语言/音素体系的规范音素；JSON 读取上限 64 KiB。inspect 显示 appearance 开关、analysis 演出分析设置与 consonants 设置。没有音频也可完整生成/保存/导出。

### 谱面演出诊断（0.8.0）

```sh
./build/chosuta-cli generate song.svp planned.chosuta --advanced-mouth --key "Bb minor" --generate-performance --performance-analysis analysis.json
```

`--performance-analysis` 写出来源音符、原始blick、音区分位数、分句及重复候选；`--performance-info` 输出含区段原因的演出JSON。已有输出默认拒绝覆盖，明确指定`--force`才覆盖。诊断是谱面推断，不能证明实际歌唱力度。默认初值经过结构回归和本地参考工程对照，其他完整歌曲及主观自然效果仍需验证。

## 工程格式与编辑工作区

0.9.2 只读写 schema14，明确拒绝旧 `.chosuta`，不自动迁移人工编辑。原文件请用保存它的对应旧版程序打开（例如 schema12 使用 0.9.0）；重新导入 SVP 只生成新工程。保存保留当前编辑状态；缺图片/工具或尚未完成导出配置不妨碍保存。

人工口形拆分后保留原片段的来源范围；移动、缩放和同源合并后仍能正确换算演出时间，保存重开及撤销/重做保持一致。不同来源的合并不猜测归属：明确诊断，人工演出保留秒快照，无法映射的自动段不冒认有效来源。

新工程演出默认只允许通用档位规则，不保存工程专属组或轨道引用。发现非法本机默认时会提示并使用内存默认；原始设置值保留，直到明确重设该项。自定义强拍模板必须至少包含一拍，空数组会被拒绝。

侧栏顶部选择轨道、素材、口形、演出、规则等页面；选中时间轴口形会显示对应属性，未选对象显示提示。规则与对象属性可滚动；输出设置/导出在上方，预览下保持播放和定位。新工程词典默认需主动勾选保存，不因编辑当前工程自动改变。

删除差分组时按稳定 ID 选择替换组，固定整图、人工项、演出与回退引用一并替换，可一次撤销。普通 PNG 导入也先进入映射草稿；无效行不影响有效行，同一目标采用最后勾选的一项；已有槽位仍通过勾选选择替换。组成员的 unknown 辅助槽也参与替换；独立自定义 ID（包括与组名同前缀的 ID）保留。

波形时间校正根据谱面依据及音频文件路径、大小和修改时间判断是否沿用；不再完整读取音频计算哈希。预览和导出共用逐帧合成，需要的图片在使用时读取。

## FFmpeg 路径与 no-ffmpeg 版

在“文件 → 导出设置”中：

1. “默认 FFmpeg（本机）”通过“浏览…”选择 `ffmpeg.exe`；留空自动查找附带工具和 PATH。按确定才保存到本机，新工程和采用自动路径的旧工程都会使用它。
2. 需要某个工程独用工具时，勾选“为本工程单独指定”并选择路径。此路径随工程保存，直接用于波形和导出；更新工具不需要再次确认。
3. 点击“检测媒体工具”查看当前填写的 FFmpeg／ffprobe 实际路径、版本及缺失编码器／滤镜。检查在后台进行，取消关闭不会保存填写值；检测通过表示工具启动和列出的能力可用，仍应试导出目标视频。

ffprobe 不必另外填写：先找所选 ffmpeg 同目录，再找附带工具／程序目录／PATH。共享构建请保留供应商配套 DLL；不能只拿走 EXE。CLI 也支持 `chosuta-cli --check-media-tools --ffmpeg <路径>`，输出 JSON；全部检查通过返回 0，缺失／失败返回 1。

no-ffmpeg 版省去外部命令行工具；没有可用 FFmpeg 时，视频导出、波形显示和重新校正不可用，工程导入／生成／编辑／保存仍可用；没有 ffprobe 时手动设置音频时长。试听由 Qt 媒体后端负责，因此不要删应用自带的 Qt 媒体 DLL 或插件。选择现有完整工具目录后即可使用相应功能，不必重新安装 Chosuta。

# Chosuta

[简体中文](README.md) | [English](README.en.md) | **日本語**

Chosutaは、歌声合成ソフトのプロジェクトと口形の異なる立ち絵を読み込み、歌唱動画を出力するソフトです。現在、SVP（Synthesizer V）の動作を確認しています。UST（UTAU）、USTX（OpenUtau）、VSQ・VSQX・VPR（VOCALOID）、CCS（CeVIO）、VVPROJ（VOICEVOX）、DS（DiffSinger）、MusicXML・XML・MXLにも対応していますが、これらは実際の歌唱プロジェクトを使った手動検証は行っていません。

## 1. 機能

SVPなどのプロジェクトと、口形ごとの立ち絵から動画を生成します。  
編集画面でアニメーションのタイミングや立ち絵差分を手動調整できます。タイムラインは小節・拍での表示にも対応しています。  
単色背景で書き出して動画編集ソフトで仕上げる使い方と、背景を読み込み、立ち絵を配置して簡単なPVを直接作る使い方があります。  
0.6.4は旧方式のアーカイブ版です。高度な設定で上行・下行、順次進行・大跳躍・小跳躍、強拍・弱拍を組み合わせ、100種類以上の差分を扱う方式を試しましたが、手間が大きく、効果も十分ではありませんでした。別の方向を検討し、この版はブランチを作らずReleaseのアーカイブとしてのみ残しています。  
0.8.2で自動差分の方式を改めました。  
1.0.0では対応ソフトを増やしましたが、追加形式の手動検証は行っていません。

## 2. 現在のバージョン

現在のバージョンは **1.0.1（schema14）** です。

## 3. システム要件

| 環境 | 要件 |
| --- | --- |
| Linux | パッケージと一致するディストリビューション・アーキテクチャが必要です。今回のバイナリはArch Linux x86_64向けです。ZIPはシステムライブラリを動的リンクし、他のディストリビューションでも単体で動く形式ではありません |
| Windows | ビルドスクリプトはWindows 10/11 x64向けです。 |
| macOS | 実験的なローカルビルドスクリプトがあります。既存のXcodeコマンドラインツールと、同じアーキテクチャのSDKが必要です。実機未検証です |
| 実行時ライブラリ | Qt ≥6.4（Core・Gui・Widgets・Concurrent・Multimediaとプラットフォーム／メディアプラグイン）、ICU ≥67。LibYAML・従来型MiniZip/zlibはプラットフォームに応じてシステム共有ライブラリまたは静的ビルドを使用します |
| 動画出力・波形 | 任意の外部FFmpeg。MP4にはlibx264/AAC、WebMにはlibvpx-vp9/libopus、透過MOVにはqtrleが必要です |
| 音声の長さの検出 | 任意のffprobe。なくても音声を追加し、長さを手動指定できます |

読み込み、口形生成、プレビュー、編集、保存に音声・音源・Synthesizer V本体は必要ありません。FFmpegのパスはアプリ内で指定できます。Python/PowerShellはアプリの実行時依存ではありません。

**ソースからビルドする場合は開発環境も必要です。**

| プラットフォーム | 事前に用意するもの | スクリプトが取得できるもの |
| --- | --- | --- |
| Linux | C++20コンパイラー、CMake ≥3.24、Ninja、Qt/ICU/LibYAML/従来型MiniZip/zlibの開発パッケージ | 既定ではシステムライブラリを使用し、システムパッケージを自動インストールしません |
| Windows | PowerShell ≥5.1、CMake ≥3.24、Ninja、対応するMSVCまたはx86_64 MinGW、Qt/ICU共有SDK | `-DownloadDependencies`でLibYAML/zlibソース、別途`-DownloadFfmpeg`で任意のメディアツールを取得します |
| macOS（実機未検証） | Xcodeコマンドラインツール、CMake ≥3.24、Ninja、対応するQt/ICU SDK。既定ではシステムのLibYAML/MiniZip/zlib開発ライブラリも必要です | ローカルソース指定、または明示的な`--download-dependencies`でLibYAML/zlibソースを取得できます |

WindowsではQt・ICU・コンパイラーのアーキテクチャ／ABIをそろえてください。MSVCはx64開発者ターミナルで実行し、MSVCアプリの実行には公式VC++ x64ランタイムも必要です。**Qt・ICU・CMake・Ninja・コンパイラーをスクリプトが自動インストールすることはありません。** Qt Testは開発テストを明示的に有効化した場合のみ必要です。

## 4. インストール

### 配布物をダウンロード

このリポジトリの **Releases** で、OSとアーキテクチャに合う添付ファイルを選んでください。公開状況、検証範囲、同梱依存は各Releaseの説明に従います。GitHubが自動生成するSource codeアーカイブはソースであり、ビルドが必要です。

- **Arch Linux**：`chosuta-<バージョン>-<パッケージ改訂>-x86_64.pkg.tar.zst`をインストールし、`chosuta`またはデスクトップメニューから起動します。実行時ライブラリはシステムパッケージが提供します。
- **Linux ZIP**：全体を展開し、`bin/chosuta`を実行します。CLIは`bin/chosuta-cli`です。対応するシステムABIとQtプラットフォーム／メディアプラグインが必要です。
- **Windows**：検証済みの実行用ZIPが提供されている場合は全体を展開し、ルートの`chosuta.exe`を実行します。DLLとプラグインを残してください。ビルドスクリプトがあることは、Windows完成品の公開を意味しません。
- **その他のLinux/macOS**：今回のArchバイナリは使えません。対象環境でソースからビルドしてください。DEB/RPMとmacOS実機は未検証です。

AURはビルドレシピを扱います。現在AURエントリーは公開していないため、yay/paru用のインストールコマンドはありません。[Linuxパッケージ説明（中国語）](docs/packaging.zh-CN.md)をご覧ください。

### ソースからビルド：Linux

上記の開発依存がある環境で、対応するソースZIPを展開するかリポジトリのソースを取得し、ソースのルートで実行します。

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build --parallel 4
./build/chosuta
```

自分が所有するディレクトリへ配置する場合：

```sh
cmake --install build --prefix "$PWD/stage"
./stage/bin/chosuta
```

既定では依存をダウンロードせず、テストのビルド・実行もしません。LinuxパッケージはシステムのQt/ICU/LibYAML/MiniZip/zlibを使い、これらやFFmpegを同梱しません。他のディストリビューション向けには対象環境で再ビルドしてください。

### ソースからビルド：Windows

先に要件表のツールとQt/ICU SDKを用意してください。MSVCではx64 Native Tools / Developer PowerShellを使います。次のコマンドは2種類のダウンロードを明示的に有効にします。

```powershell
.\scripts\build-windows.ps1 `
  -QtPrefix '<Qt x64 SDKのプレフィックス>' `
  -IcuPrefix '<ICU x64 SDKのプレフィックス>' `
  -DownloadDependencies -DownloadFfmpeg
```

| オプション | 動作 |
| --- | --- |
| `-DownloadDependencies` | 固定版LibYAML 0.2.5とzlib 1.3.2（MiniZipを含む）のソースを取得してSHA-256を検証し、既存C/C++ツールチェーンで静的ビルドします。使用した完全なソースとライセンスを配置物に残します |
| `-DownloadFfmpeg` | アプリのビルド成功後、BtbN公式リリースからwin64 GPL sharedのFFmpeg/ffprobeとDLLを取得し、検証・キャッシュします。次回はオフラインで再利用できます |
| `-LibYamlSourceDir`と`-ZlibSourceDir` | 完全なローカルソースを2つ指定し、`-DownloadDependencies`の代わりにオフラインビルドします。指定したローカルソースが優先されます |
| `-FfmpegDir` | 既存のffmpeg.exe・ffprobe.exe・DLLがあるbinディレクトリを指定します。`-DownloadFfmpeg`とは併用できません |
| `-Toolchain MinGW` | Qt/ICUに合うx86_64 MinGWを使用します。既定はMSVCです |
| `-BothVariants -CreateZip` | 1回のビルドからツール同梱版とno-ffmpeg版のディレクトリ・ZIPを作ります。メディアツールの取得元も指定してください |

**既定はオフラインです。自動取得には明示的なオプションが必要です。** メディアツールを指定しなければFFmpegを取得・同梱しませんが、編集・保存は使えます。no-ffmpeg版にもQtメディアバックエンドは残り、すべてのメディアDLLを取り除くわけではありません。

既定の出力先は`out/windows/Chosuta/chosuta.exe`と`chosuta-cli.exe`で、外部ツールは`tools/ffmpeg/`に置きます。スクリプトは事前確認したCMake/Ninja/コンパイラーを固定し、Ninja/Release・`BUILD_TESTING=OFF`で処理します。SDKのインストール、恒久的なPATH変更、CTest、アプリの自動起動は行いません。Builtと表示されたらGUIを手動起動できます。配置ディレクトリ全体を残してください。出力先は空で、ZIPは未作成である必要があります。再実行には`-StageDir 'out/windows/Chosuta-new'`などを指定します。[Windows説明（中国語）](docs/windows.zh-CN.md)をご覧ください。

### ソースからビルド：macOS（実機未検証）

```sh
bash scripts/build-macos.sh --qt-prefix '<Qt macOS SDKのプレフィックス>' --icu-prefix '<ICUのプレフィックス>'
```

既定はオフラインです。`--libyaml-source-dir`・`--zlib-source-dir`、または明示的な`--download-dependencies`を指定できます。ローカルSDKを使い、`out/macos/Chosuta/chosuta.app`と`bin/chosuta-cli`を生成します。ツールのインストール、ランタイムのコピー、FFmpegの取得、署名・公証は行いません。macOS実機は未検証です。[macOS説明（中国語）](docs/macos.zh-CN.md)と[ビルド説明（中国語）](docs/building.zh-CN.md)をご覧ください。

### その他の機能

#### キャンバス設定と立ち絵の配置

ページ選択の **「キャンバス / 背景」** で、画面サイズ、背景色、立ち絵の大きさ・位置などを変更できます。再生停止中に **「立ち絵の配置をドラッグ」** を選ぶと、キャンバス上で直接動かせます。  
<img width="780" height="797" alt="image" src="https://github.com/user-attachments/assets/9fc52b8d-6455-47a8-8c67-829c8969e7f8" />  
一般的にはGB素材として書き出し、Premiere Proなどの動画編集ソフトで仕上げます。複雑なPVが不要なら、背景を読み込んでそのまま動画にすることもできます。

#### 音声の追加と波形補正

キャンバス下の **「音声を追加」** を押すか、音声ファイルをウィンドウへドロップします。プロジェクトより音声が長いときはアニメーションを延長するか確認します。音声とプロジェクトの位置を合わせてください。  
タイムライン上の **「波形でタイミングを補正」** で、波形から音節のタイミングを補正できます。歌声合成ソフト側のタイミング調整などによる、譜面と実際の歌唱のずれを軽減できる場合があります。  
<img width="1911" height="477" alt="image" src="https://github.com/user-attachments/assets/562e6437-f97d-4e33-ac13-233bca0c2b14" />  
波形のエネルギーから時間を推定するだけで、音素・口形・旋律の認識はしません。参考・補助として使ってください。音声を差し替えると以前の補正は無効になり、新しい音声での再補正が必要です。伴奏を含むミックスでは歌声の境界が不明確になる場合があります。  
1か所の誤推定で曲全体がずれないよう、最大ずれに上限があります。値は変更できます。

#### 表示・トランスポート・手動補正

手動補正を助けるため、次の操作を用意しています。

- **小節 / 拍**：タイムライン上で秒表示と小節・拍表示を切り替えます。BPMはプロジェクトから取得するため、ここでの変更はできません。
- **停止時に再生開始位置へ戻る**：左上の **「トランスポート」** で有効にできます。DAWに近い操作になります。
- **カーソル：拍に吸着** / **カーソル：音節に吸着**：タイムライン上で拍または音節への吸着を選べます。
- **ズームと移動**：ズームスライダーまたはCtrl＋ホイールで拡大縮小し、下のスクロールバーまたは中ボタンドラッグで表示範囲を移動します。
- **口形ブロック**：クリックして差分や開始・終了を設定し、分割・結合できます。中央のドラッグで移動、端のドラッグで長さを変更できます。

#### 字幕の追加

タイムライン上の **「字幕を追加」** を有効にすると字幕トラックが追加されます。字幕レーンの空白をダブルクリックするとブロックを作れます。ブロックや端をドラッグして移動・長さ変更、ブロックをダブルクリックして文字編集ができます。  
<img width="1923" height="1397" alt="image" src="https://github.com/user-attachments/assets/cbb67c66-f3f3-4731-ad0b-e37195f70d4d" />  
編集画面ではフォント・色・大きさ・位置などを選べます。字幕の位置はキャンバスでも直接動かせます。  
Chosutaは動画編集ソフトではなく、字幕は補助機能です。本格的な字幕や字幕演出は、書き出した動画を専用の機能があるソフトで編集してください。

#### 子音規則

多くの歌声合成ソフトでは、実際の母音・子音の時間配分はプロジェクトではなくレンダリングキャッシュにあります。Chosutaはその配分を読めないため、割合と時間上限を使います。「ルール」で変更でき、境界を手動で動かすこともできます。  
<img width="764" height="274" alt="image" src="https://github.com/user-attachments/assets/7e17986a-2bb4-41a2-a248-f91d01110f0b" />  
子音ごとに口の形は異なり、/k/・/g/・/h/は開口、/b/・/p/・/m/は閉口、/f/・/v/は半閉口です。すべての形を列挙すると必要な素材が増えすぎるため、既定では/b/・/p/・/m/を閉口にし、その他の対応子音は母音の口形を使います。**「PNG 差分」→「高度な差分設定」→「子音規則」** で変更できますが、既定値の変更は推奨しません。

### 高度な差分と自動演出

#### 方式の変更

廃止した0.6.4では、上行・下行、順次進行・跳躍、強拍・弱拍などを組み合わせましたが、必要な差分が膨らみ、旋律の音程だけでは演出をうまく判断できませんでした。この方式は終了していますが、Releaseのアーカイブを試すことはできます。  
現在は前後のノートから強調・抑制を判断する方式です。まだ多くの曲を十分に扱えるわけではなく、改善には追加の楽曲やご意見が必要です。

#### 高度な差分の有効化とグループ設定

「PNG 差分」の上部で **「高度な差分を有効化」** をオンにします。  
**「高度な差分設定」→「差分画像」** を開きます。最初は **Base** グループだけがあり、**「通常」「強調」「控えめ」** のすべてにBaseを使います。**「グループ追加」** で新しいグループを作り、口形ごとの立ち絵を登録して、各役割へ割り当てます。  
<img width="1474" height="1127" alt="image" src="https://github.com/user-attachments/assets/fac226ee-f85c-4255-ae78-85ae12330ee6" />  
グループ設定は自動では確定しません。下の **「適用」** で演出に反映します。  
**「一括読込」** で複数のPNGやフォルダーを読み込み、**「すべての行を選択」** で全行を選び、対象グループを選んで **「選択行のグループを変更」** を押すこともできます。**「選択を解除」** は行選択を解除します。行の選択は「読込」チェックを変更せず、既存画像の置換にはチェックが必要です。

## 6. 実装の仕組み

C++20・Qt 6 Widgets・ICUを使用し、コアモデルはGUIから独立しています。ソースの譜面・明示音素・歌詞を決定的な規則で処理して口形を生成します。合成ソフト本体、音源、レンダリングキャッシュ、ニューラルネットワークは不要です。音声は試聴、動画の音声、明示的に実行する時間補正に使います。

1. **ソースと時間**：SVP・UST・USTX・旧VSQ（DSB301）・VSQX・MusicXML/MXL・CCS song・基本的なVPR歌声トラック・VVPROJ songと、LAB・完全な時間情報のあるDS・完全なqueryを持つVVPROJ talkを共通経路で読み込みます。元のバイト列、整数位置、解像度、トラック／グループ参照の識別情報を保持します。SVPは実際に参照されたmainGroup/mainRefとlibraryだけを展開し、時間・音高オフセットを適用します。四分音符は705,600,000 blickで、テンポごとに秒へ変換し、拍子から小節・拍を求めます。LAB/DS/talkは絶対時間の音素を使い、音高や拍を作りません。混在VVPROJは歌と会話を別々に選びます。形式ごとに対応範囲があり、すべての製品バージョンの手動検証を意味しません。[形式説明（中国語）](docs/user-guide.zh-CN.md)を参照してください。
2. **読みと口形**：ロック済み編集、ノート単位の修正、空でない明示音素を優先し、その後にユーザー辞書・内蔵規則を使います。日本語は仮名・ローマ字が基本で、漢字推定は既定で無効です。中国語は一般語・ピンイン・ICU Han-Latin、英語は小規模な独自語彙表を使います。3言語の独自表は合計約14 KBです。内蔵・独自・任意の外部辞書を合わせて3,000,000バイト以内とし、編集とJSON入出力に対応します。未知の読みは要確認のまま残します。明示音素や手動の読みがない空の歌詞はrestが既定で、保存済みの方針は保持します。継続・長音・閉鎖・ブレス・休止は別々に扱います。先行・末尾の子音群に割合と既定80 msの上限をそれぞれ適用し、0は固定上限なしです。b/p/mなどの両唇音は閉口、その他の対応子音は母音追従が既定で、変更できます。意味を確認できていないSVのleftOffsetは保存と診断のみ行います。
3. **差分グループと自動演出**：既定はシンプルモードです。高度なモードは「差分グループ×口形」で全身画像を選び、口形生成と演出グループ選択を独立させます。各グループには5母音と閉口・休息・ブレスの主8枠があり、補助のunknown画像も保持します。画像がなければ現在のグループの同口形、基本グループの同口形、全体の代替画像の順で探します。自動演出は譜面の背景、限定的な反復モチーフ、到達音群を分析します。抑制には持続的な下降、発音間隔の拡大、終端の根拠を組み合わせ、同音・短い折返し・息継ぎでは維持できます。実際の音量や感情は認識しません。主音と旋法を別々に選び、時間（音楽時間／秒）・距離（半音／度数）は選択した基準だけが有効です。高度な設定の「適用」は保護された手動区間を残して自動演出を更新します。別途生成する場合は案の比較、適用・キャンセル、範囲再生成ができます。CLIは譜面診断を書き出せます。
4. **手動編集と素材読込**：口形イベントと独立した演出区間を編集・分割・結合・保護でき、元に戻せます。演出テンプレートは「保持」「展開」「収束」「展開して収束」です。通常の口形編集はグループに追従し、全体画像を明示的に固定した場合だけグループ選択を迂回します。演出編集は波形補正を消しません。口形の分割・移動・伸縮・同一ソースの結合はソース断片を保持し、後の時間変換に使います。ソースをまたいで曖昧な場合は秒スナップショットを残して診断します。PNG／フォルダー読込は任意のファイル名、行別の割当、全行選択・解除、一括グループ指定、縮小表示、ドロップに対応します。行選択と読込チェックは独立です。置換はチェックで確認し、同じ枠はチェック済み有効行の最後を使って、まず設定の下書きへ反映します。
5. **タイムラインと字幕**：タイムラインは表示領域以上の幅を確保し、ウィンドウ幅に追従します。長い内容は横スクロールでき、ウィンドウ幅で行高や時間倍率は変わりません。中ボタンで移動し、ズームスライダーは画面内の再生ヘッド、画面外なら表示中央を基準にします。Ctrl＋ホイールはポインター位置を基準とし、スクロールの端では制限されます。移動位置の指定はルーラー、その他の空白は選択解除に使い、カーソルは拍・音節へ吸着できます。再生ボタン・スペース・「トランスポート」は再生／停止と開始位置へ戻る設定を共用します。字幕は既定で無効で、複数トラック、ブロック内編集、基本スタイルに対応します。歌詞との同期は指定トラックの譜面時間を使い、音声や文意を認識しません。字幕は口形と独立して再生成でも保持されます。停止中のプレビューで立ち絵・字幕の配置を編集でき、1回のドラッグを1回で元に戻せます。文字編集は1つのネイティブQtコントロールを再利用します。フォントはローカル環境のもので、別のPCでは置換される場合があります。
6. **波形と時間補正**：波形はルーラーの下、口形行の上にあり、表示高を変えても音声の時間は変わりません。読込だけでは表示にとどまり、「波形でタイミングを補正」で譜面境界付近の明確な開始・終了を推定します。既定は最大ずれ100 ms・最大時間変化25%で、変更・保存できます。各補正は独立し、ずれを累積せず、音素・口形・区間内比率を変えません。不明確・競合・手動保護の位置は元の結果を保ちます。補正は取消・復元でき、プレビューと出力で共有します。譜面情報と音声のパス・サイズ・更新時刻で有効性を判断し、再生成や入力・音声の変更で無効になる場合があります。音声内容のハッシュは計算しません。TimingRefinerインターフェースは残しますが、音素認識・音源分離・モデル依存はありません。CLIにはcorrect/revertがあります。
7. **プロジェクトと言語**：現在のschema14だけを読み書きし、旧schemaは移行しません。古いファイルは残して対応する旧版で開いてください。元のソースを内包し、sourceFormatで解析方法を決めます。現在のschema14でこの項目がない場合はSVPです。元ソース・生成結果・手動上書き・演出・補正を別々に保存し、再生成でもロック済み編集を保ちます。操作は元に戻す・やり直し、素材の相対パス・再指定に対応します。画面、エラー、一般的なQtコントロール、構造化した演出理由は中英日表示ができ、外部ツールの原文エラーは技術詳細に残します。言語変更でデータIDや履歴は変わりません。
8. **合成と外部ツール**：プレビュー・タイムライン・動画出力はイベント評価とScene合成を共用し、各フレームの絶対時間から口形・演出・字幕・背景・立ち絵位置を求めます。画像は必要時にデコードし、上限付き共有キャッシュを使い、メディアパスは直接利用します。外部FFmpegは実行パスと引数配列で起動し、音声なしでも出力できます。書き出し設定にはPC既定パス・プロジェクト個別指定・非同期確認があり、ffprobeは選んだFFmpegに追従します。WindowsはGUI/CLIを配置ルートに置き、Qt/ICU DLL・プラグインを保持し、外部ツールをtools/ffmpeg/に置きます。1回のビルドで同梱版とno-ffmpeg版を作れますが、後者にもQtメディア依存は残ります。提供されたロゴをウィンドウ・Windows EXE・Linuxデスクトップアイコンに使い、新しい画像処理ランタイムは追加しません。

自動結果はアニメーションの時間推定であり、合成ソフト独自の音響モデルを再現しません。操作・形式の範囲・制限は[使用説明（中国語）](docs/user-guide.zh-CN.md)をご覧ください。
